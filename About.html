01 — How I think about the work

A few habits that have stuck.

01    Start at the slow step.

Before I get into specs, I try to figure out where the actual constraint is. Sometimes it's an obvious bottleneck; sometimes it's a thing nobody's measuring yet. Either way, that's usually where the spec needs to start.

02    Build the system, not just the feature.

A tool is a tool. A system that's measurably faster or cheaper is what tends to stay. That sometimes means killing a feature I was attached to — which is fine, that's part of the job.

03    Instrument before launch, not after.

If we can't see the metric move on a dashboard, I'm not really sure if we changed anything. So I try to get the measurement in first. This is the one thing I'll usually push back on engineering about.
